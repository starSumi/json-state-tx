# Contributing

Thank you for improving `json-state-tx`. The project accepts small changes that strengthen its single-file transaction contract.

Before opening a pull request:

1. Use Rust 1.89 or newer and keep `Cargo.lock` current.
2. Add regression tests for protocol, error, durability, or compatibility changes.
3. Run the checks in `AGENTS.md`.
4. Update `docs/architecture.md` when guarantees or limitations change.
5. Complete the value and compatibility questions in the pull request template.

Unless stated otherwise, contributions are licensed under the MIT license. No CLA is required.
